# Catalogue import pack

- `catalogue-1000.csv` is a copy of the generated 1,000-row project fixture.
- `import-1000-record.json` is a copy of the preserved API import metrics record.
- `import-smoke.csv` is a separate fixture used to capture a real job response and its row
  error CSV; its output files are written after that job completes.

The originals `samples/catalogue/catalogue-1000.csv` and
`evidence/catalogue-1000-import.json` remain the canonical test input and evidence.
